# noctalia modified dots

shifted from the previous end4 dots to [noctalia desktop shell](https://noctalia.dev/)

Note that I modified the dots solely thru the GUI not the TOML file.

> [!NOTE]
> 
> hypr config is still in the now deprecated `.conf` format, i cba to port it to lua, 
> will likely remain like this.
> 

> [!WARNING]
> 
> some folders maybe outdated and unmaintained (like matugen, spicetify, etc.)

## preferred theme

I prefer gruvbox and as such all the wallpapers I have are all either of that schema or the outliers are the ones I really like.

## nvim

nvim config is a more modified and monkeypatched nvchad conf that mainly suitable for **c/c++/rust** etc. languages

## emacs

am trying out doom emacs with some small changes here and there to match certain nvchads ergonomics (like floating terminal, etc.)

Check out [doom emacs](https://github.com/doomemacs/core) for more info.

## installation guide (simple)

If you are on Arch Linux or any derivatives of it, should be straightforward:

```bash 
sudo pacman -S noctalia hyprland nvim emacs
```
